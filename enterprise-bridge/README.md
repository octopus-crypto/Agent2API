# WorkBuddy 企业专享版本机适配层

此适配层使用腾讯官方 Agent SDK 和独立的官方登录配置，将**单条用户文本**转换为有限的 OpenAI 兼容非流式对话。当前属于待验证配置：企业账号的真实模型推理、模型来源和使用授权尚未通过验收。流式、多轮、工具调用及其他请求参数会明确返回错误；不要用它替代已验证的 Trae 或 WorkBuddy 公开版。

## 配置与启动

使用 Node.js 22 或更高版本，在本目录执行 `npm ci --ignore-scripts`。通过腾讯官方 CodeBuddy 的企业域名登录完成授权，并将其配置保存在独立目录。随后在项目被忽略的 `.verify/enterprise-bridge-config.json` 中创建本机配置。以下值均为示意，实际密钥必须随机生成并保密：

```json
{
  "port": 3067,
  "nodePath": "D:\\path\\to\\node.exe",
  "codebuddyConfigDir": "D:\\path\\to\\isolated-codebuddy-config",
  "endpoint": "https://example.com",
  "bridgeKey": "替换为至少32字符的随机密钥",
  "models": ["实际配置的企业模型名"]
}
```

配置文件包含密钥和企业地址，应限制为当前用户访问，不得提交、分享或写入日志。`models` 是管理员或用户确认的本机配置列表；接口返回这些名称不代表它们已获得模型推理权限。SDK 的登录凭据由官方工具管理，适配层不读取或导出这些凭据。

从 PowerShell 运行 `./enterprise-bridge/manage.ps1 -Action start`。脚本只允许适配层监听 `127.0.0.1`，检查 Node.js、依赖、受控进程和端口占用；重复启动会检查已有实例。使用 `status`、`stop` 或 `restart` 管理同一实例。日志与进程记录保存在 `.verify` 下。若端口被未知进程占用，脚本会拒绝启动，也不会停止该进程。

## Agent2API 中的账号

可在 Agent2API 中通过自定义提供商配置指向 `http://127.0.0.1:3067/v1`，账号密钥使用同一份本机 `bridgeKey`。企业账号及其模型应保持禁用，并明确标记“待验证”，直到企业授权、额度、推理和实际来源得到验证；适配层返回的模型清单不能作为通过证据。企业模型应使用单独的对外别名，避免与其他提供商模型混淆。

当前适配层不会自动随桌面应用启动。完整使用前，需要验证实例重启、真实非流式调用、流式、多轮和工具调用，以及与其他提供商互不影响；其中未实现的能力不能标为通过。

## 本地测试

使用 Node.js 22 运行 `node --test`。这些测试使用替身验证本地协议、鉴权和错误处理，不会访问企业模型，也不能替代真实推理验证。
